# Project J

**We build small language models (SLMs) for the open research community and the advancement of open science [(link to our HuggingFace models)](https://huggingface.co/projectj).**

This repo contains the following projects (folders):

[jym/](./jym/README.md)

A platform to test AI models in various environments.
Contains a flight simulator environment based on JSBSim flight dynamics software.

[training/](./training/README.md)

Our model training scripts.
Contains source code to train a quick decision-making flight simulator model with reinforcement learning (imitation + PPO).
